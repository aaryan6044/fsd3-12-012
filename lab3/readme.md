## http status codes

- 200 -> OK
- 201 -> Created
- 400 -> Bad Request 
- 401 -> Unauthorized
- 403 -> Forbidden
- 404 -> Not found
- 500 -> Internal Server Error


### Sender can send this file to the client
1. html file -> prg5
2. json data -> prg4
3. plain file
4. js file
5. any file to download 
7. etc



## Type of information 
1. text/html -> for html file/contents
2. text/json -> for json data
3. text/css -> for css file/contents
4. application -> for file 
5. text/plain -> for plain text file
